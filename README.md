# House Search Digest

Personal Saturday digest of single-family homes for sale in the South Bay, Westside, Long Beach, and San Pedro. The site is static: `index.html`, `styles.css`, `app.js`, and one file per week under `weeks/`. There is no build step and no third-party tracking.

GitHub Pages serves this repository from the `main` branch, folder `/`.

Open `index.html` in a browser. The scripts are local, so the file works without a server. A week can be linked as `#2026-11-21`. The newest week opens when the hash is empty.

## Add a week

A weekly update touches two files: a new `weeks/YYYY-MM-DD.js`, and one new line in `weeks/manifest.js`. Do not edit older files in `weeks/`, and do not edit `index.html` or `app.js`.

1. Create `weeks/YYYY-MM-DD.js`. Copy the wrapper from `weeks/2026-11-21.js`, then replace the object with that Saturday’s facts. The date in the file name and in `HOUSE_WEEKS["YYYY-MM-DD"]` must match.

```javascript
/* Week of YYYY-MM-DD. Do not edit this file after it is published.
   Leave an unknown field as "". The page shows n/a.
*/
window.HOUSE_WEEKS = window.HOUSE_WEEKS || {};
window.HOUSE_WEEKS["YYYY-MM-DD"] = {
  "title": "House Search Digest — <date>",
  "weekLabel": "Saturday, <date>",
  "lede": "Single-family homes for sale in the South Bay, Westside, Long Beach, and San Pedro.",
  "top10": [],
  "otherQualifying": [],
  "newThisWeek": { "intro": "", "listings": [], "notVetted": "", "qualifyingIntro": "", "qualifying": [] },
  "priceChanges": [],
  "priceChangeNote": "",
  "statusChanges": [],
  "corrections": [],
  "nearMisses": [],
  "openQuestions": [],
  "caveat": { "title": "", "paragraphs": [] },
  "criteriaSummary": "",
  "criteria": [],
  "methodNotes": []
};
```

2. Append that date, and only that date, to the array in `weeks/manifest.js`:

```javascript
window.HOUSE_MANIFEST = [
  "2026-11-21",
  "YYYY-MM-DD"
];
```

Copy prices, ratings, scores, commute times, and listing URLs exactly. Leave an unknown field as `""`. The page shows `n/a`. Do not add a home that is not in that week’s digest. `hoaPenalty` is `"—"` when no gated-HOA penalty applies. Areas in `otherQualifying` drive the filter. `Long Beach`, `San Pedro`, and `Lomita` stay in that order. Any other `area` value is added automatically.

The tab label is `weekLabel`. Tabs are ordered newest first. `#YYYY-MM-DD` opens that week. `#YYYY-MM-DD/top-10` also scrolls to a section (`top-10`, `radnor`, `other`, `new`, `changes`, `near-misses`, `questions`, `caveat`, `criteria`).

## What’s on each week

Top 10 with weighted scores (interior 35%, space 25%, commute 20%, school 20%) and the gated-HOA penalty, the status callout, other qualifying homes with an area filter, an ADU column, and a score, new listings, price changes and corrections, near-misses, open questions, the school caveat, and the buyer criteria.
